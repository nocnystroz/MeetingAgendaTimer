# Warunki użytkowania

Licznik spotkaniowy działa lokalnie. Odliczanie i notatki nie wymagają konta.
Nagrywanie, zrzuty i transkrypcja są funkcjami dobrowolnymi.

## Zgody uczestników

**Nagrywając audio lub wykonując zrzuty ekranu/okna, oświadczasz, że masz zgodę
uczestników na utrwalenie spotkania w tym zakresie oraz wymagane uprawnienia.**
Przed użyciem tych funkcji poinformuj uczestników o zakresie i celu zapisu.
Nie korzystaj z nich, jeśli nie masz wymaganych zgód lub uprawnień.

Zrzuty mogą utrwalić prywatne wiadomości, dane osobowe i treści innych aplikacji.
Wybierasz źródło i odpowiadasz za zakres zapisu, przechowywanie i udostępnianie
powstałych plików. Zgoda systemu na dostęp do mikrofonu/ekranu nie zastępuje
zgody uczestników.

## Transkrypcja API

Transkrypcja wymaga własnego klucza i osobnego potwierdzenia wysłania audio
do OpenAI. Wysyłając nagranie, potwierdzasz również, że możesz przekazać je temu
dostawcy. Koszty API obciążają Twoje konto. Anulowanie nie cofa danych już
wysłanych ani ewentualnych opłat. Agenda, notatki i zrzuty nie są wysyłane.

## Dane i niezawodność

Dane lokalne nie są automatycznie szyfrowane. Chroń urządzenie i swoje pliki.
Eksporty oraz wybrane katalogi mogą podlegać Twoim kopiom zapasowym lub
synchronizacji. Aplikacja jest prototypem: wykonuj kopie ważnych danych
i nie polegaj wyłącznie na nagraniu lub transkrypcji.
